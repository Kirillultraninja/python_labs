Функция normalize:
Приводит текст к нижнему регистру (или casefold), заменяет «ё» на «е» и удаляет лишние пробелы, схлопывая все пробельные символы в один.

Функция tokenize:
Разбивает текст на список слов с помощью регулярного выражения, которое извлекает последовательности букв, цифр и подчёркиваний, включая дефисы внутри слов (например, «по-настоящему»).
