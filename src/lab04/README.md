## Задание A — модуль src/lab04/io_txt_csv.py
Создан модуль для чтения TXT-файлов и экспорта результатов в CSV. Используются стандартные средства Python: Path для обработки путей и модуль csv для сериализации данных.

# Реализованные функции:
1.read_text Функция осуществляет полное считывание файла и возвращает его содержимое в виде единой строки. По умолчанию применяется кодировка UTF-8, однако предусмотрена возможность указания другой кодировки (например, encoding="cp1251"). При отсутствии файла возбуждается исключение FileNotFoundError, а при ошибке декодирования — UnicodeDecodeError.

2.write_csv Функция предназначена для записи строк в CSV-файл. Перед сохранением выполняется валидация: все строки должны иметь одинаковую длину, в противном случае возбуждается исключение ValueError. Если передан аргумент header, он добавляется в файл в качестве первой строки.

3.ensure_parent_dir Функция осуществляет проверку существования родительского каталога и, при его отсутствии, рекурсивно создает его, включая всю цепочку недостающих вложенных директорий.
